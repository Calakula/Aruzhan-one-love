В проекте нет jQueryЖобада jQuery жоқThere is no jQuery in the project

Критерий 4 (9 баллов) прямо требует «минимум 3 разных jQuery-эффекта», а бриф говорит «forms, JavaScript and jQuery». Я проверил все HTML, JS и CSS — слов jquery и $( в коде нет: плавный скролл, окна, переворот карточек, появление — всё на чистом JS/CSS. Переменная $ в quiz.js — просто короткое имя для getElementById. Что делать: подключить jQuery (CDN, фиксированная версия) и сделать минимум 3 эффекта (например, slideToggle для аккордеона фактов, animate для плавного скролла, fadeIn для сообщения после формы). Могу сделать это в коде проекта — скажите.4-критерий (9 ұпай) «кемінде 3 түрлі jQuery-эффект» дегенді тікелей талап етеді, ал бриф «forms, JavaScript and jQuery» дейді. Мен барлық HTML, JS және CSS тексердім — кодта jquery және $( сөздері жоқ: тегіс скролл, терезелер, карточкаларды аудару, пайда болу — бәрі таза JS/CSS. quiz.js-тегі $ айнымалысы — getElementById үшін қысқа ат қана. Не істеу керек: jQuery қосу (CDN, бекітілген нұсқа) және кемінде 3 эффект жасау (мысалы, фактілер аккордеоны үшін slideToggle, тегіс скролл үшін animate, форма кейінгі хабар үшін fadeIn). Мұны жоба кодына өзім қоса аламын — айтыңыз.Criterion 4 (9 points) explicitly requires “at least 3 different jQuery effects”, and the brief says “forms, JavaScript and jQuery”. I checked every HTML, JS and CSS file — the words jquery and $( do not appear: smooth scroll, modals, card flips, reveal — everything is plain JS/CSS. The $ in quiz.js is just a short name for getElementById. What to do: load jQuery (CDN, pinned version) and add at least 3 effects (e.g. slideToggle for a facts accordion, animate for smooth scroll, fadeIn for the post-form message). I can add this to the project code — just say so.

Словарь терминовТерминдер сөздігіGlossary

Термины, которые встречаются в нашем коде и на которые могут обратить внимание.Біздің кодта кездесетін және назар аударылуы мүмкін терминдер.Terms that appear in our code and that the instructor may pick on.

IIFE
Функция, которая вызывается сразу после объявления: (function () { … })();. Даёт приватную область видимости.Жарияланған бойда шақырылатын функция: (function () { … })();. Жеке көру аймағын береді.A function called right after being defined: (function () { … })();. Gives a private scope.
DOM
Дерево элементов страницы, которым управляет JS: getElementById, querySelector, createElement, appendChild.JS басқаратын бет элементтерінің ағашы: getElementById, querySelector, createElement, appendChild.The tree of page elements that JS controls: getElementById, querySelector, createElement, appendChild.
Event / Listener
Событие (click, input, change, submit, keydown) и функция-обработчик, добавленная через addEventListener.Оқиға (click, input, change, submit, keydown) және addEventListener арқылы қосылған өңдеуші функция.An event (click, input, change, submit, keydown) and a handler function added via addEventListener.
Event bubbling
Событие «всплывает» от внутреннего элемента к родителям; поэтому один обработчик на обёртке ловит события полей внутри.Оқиға ішкі элементтен ата-аналарға «көтеріледі»; сондықтан орауыштағы бір өңдеуші ішкі өрістердің оқиғаларын ұстайды.An event “bubbles” from the inner element to its parents; so one handler on a wrapper catches events of the fields inside.
Closure
Функция помнит переменные из места, где создана (например, i в обработчике клика внутри цикла).Функция өзі жасалған жердегі айнымалыларды есте сақтайды (мысалы, цикл ішіндегі шерту өңдеушісіндегі i).A function remembers the variables from where it was created (e.g. i in a click handler inside a loop).
dataset / data-*
Свои атрибуты HTML data-name="…", доступные в JS как el.dataset.name.Өз HTML атрибуттары data-name="…", JS-те el.dataset.name ретінде қолжетімді.Custom HTML attributes data-name="…", available in JS as el.dataset.name.
localStorage
Хранилище «ключ → строка» в браузере; данные остаются после закрытия вкладки.Браузердегі «кілт → жол» сақтауы; қойынды жапқаннан кейін де деректер қалады.A “key → string” store in the browser; data stays after the tab is closed.
Promise
Объект «результат придёт позже» (например, audio.play()); ошибки ловятся через .catch().«Нәтиже кейінірек келеді» нысаны (мысалы, audio.play()); қателер .catch() арқылы ұсталады.An object meaning “the result arrives later” (e.g. audio.play()); errors are caught with .catch().
RegExp
Регулярное выражение — шаблон для проверки строки: /^\d{4}$/ = ровно 4 цифры.Тұрақты өрнек — жолды тексеру үлгісі: /^\d{4}$/ = дәл 4 сан.A regular expression — a pattern to test a string: /^\d{4}$/ = exactly 4 digits.
map / filter / forEach
forEach — выполнить для каждого; map — преобразовать каждый; filter — оставить подходящие.forEach — әрқайсысына орындау; map — әрқайсысын түрлендіру; filter — сәйкестерін қалдыру.forEach — run for each; map — transform each; filter — keep the matching ones.
setTimeout / setInterval
Один раз через N мс / повторять каждые N мс. Используются для задержек и отсчёта.N мс-тан кейін бір рет / әр N мс сайын қайталау. Кідірістер мен санақ үшін қолданылады.Once after N ms / repeat every N ms. Used for delays and the countdown.
requestAnimationFrame
Просит браузер вызвать функцию перед следующей отрисовкой — основа плавных анимаций (конфетти).Браузерден келесі салу алдында функцияны шақыруды сұрайды — тегіс анимациялардың негізі (конфетти).Asks the browser to call a function before the next repaint — the basis of smooth animation (confetti).
IntersectionObserver
Сообщает, когда элемент появился в окне просмотра (timeline.js).Элемент көру терезесінде пайда болған кезде хабарлайды (timeline.js).Reports when an element enters the viewport (timeline.js).
ARIA / a11y
Атрибуты доступности: aria-label, aria-expanded, role — помогают скринридерам и клавиатуре.Қолжетімділік атрибуттары: aria-label, aria-expanded, role — экран оқу құралдары мен пернетақтаға көмектеседі.Accessibility attributes: aria-label, aria-expanded, role — help screen readers and the keyboard.
