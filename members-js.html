Что такое dataset?dataset дегеніміз не?What is dataset?
Свойство элемента, которое даёт доступ ко всем атрибутам вида data-* как к обычному объекту. Удобно хранить небольшие данные прямо в HTML.
Элементтің data-* түріндегі барлық атрибутына қарапайым нысан ретінде қол жеткізетін қасиеті. Шағын деректерді тікелей HTML-де сақтауға ыңғайлы.
An element property giving access to all data-* attributes as a plain object. Handy for keeping small data right in the HTML.
Почему каждый обработчик «знает» свою карточку?Неге әр өңдеуші «өз» карточкасын біледі?Why does each handler “know” its own card?
Замыкание: функция клика создаётся внутри forEach и запоминает переменную c этой итерации.
Тұйықталу: шерту функциясы forEach ішінде жасалып, осы итерацияның c айнымалысын есте сақтайды.
A closure: the click function is created inside forEach and remembers the c of that iteration.
Что произойдёт, если main.js не загрузился?main.js жүктелмесе не болады?What if main.js did not load?
window.BorahaeModal будет undefined, клик вызовет ошибку в консоли. Поэтому main.js подключается раньше и является общей зависимостью.
window.BorahaeModal undefined болады, шерту консольде қате шығарады. Сондықтан main.js бұрын қосылады және ортақ тәуелділік болып табылады.
window.BorahaeModal is undefined and the click throws an error in the console. That is why main.js is loaded first as a shared dependency.
Как перевернуть карточку без JS?Карточканы JS-сіз қалай аударуға болады?How does the card flip without JS?
Через CSS: transform: rotateY(180deg) на внутреннем блоке при :hover/:focus, backface-visibility: hidden прячет обратную сторону. Файл CSS: css/style.css.
CSS арқылы: ішкі блокта :hover/:focus кезінде transform: rotateY(180deg), backface-visibility: hidden артқы жағын жасырады. CSS файлы: css/style.css.
With CSS: transform: rotateY(180deg) on the inner block on :hover/:focus, backface-visibility: hidden hides the back side. CSS file: css/style.css.
