HTML + CSS

JS-файлы работают только вместе с разметкой. Здесь — те места HTML и CSS, на которые опирается скрипт: идентификаторы, data-*, классы состояний. Если инструктор откроет HTML и спросит «откуда скрипт берёт этот элемент?», ответ — в этих фрагментах. Фрагменты взяты из реальных файлов (длинные строки сокращены знаком …).JS файлдары тек белгілемемен бірге жұмыс істейді. Мұнда — скрипт сүйенетін HTML және CSS орындары: идентификаторлар, data-*, күй кластары. Нұсқаушы HTML ашып, «скрипт бұл элементті қайдан алады?» деп сұраса — жауап осы үзінділерде. Үзінділер нақты файлдардан алынған (ұзын жолдар … белгісімен қысқартылған).The JS files only work together with the markup. Here are the HTML and CSS places the scripts rely on: ids, data-*, state classes. If the instructor opens the HTML and asks “where does the script get this element?”, the answer is in these fragments. Fragments come from the real files (long lines shortened with …).

Әр бетте — өз екінші скрипті (home.js, join.js, members.js, discography.js, quiz.js, timeline.js).Scripts are at the end of <body>: elements are already parsed when they run. Order matters: main.js creates window.BorahaeModal and the page script uses it. Every page has its own second script (home.js, join.js, members.js, discography.js, quiz.js, timeline.js).

Каждое поле лежит в обёртке с data-field="имя" — по нему holder(n) в join.js находит блок и пишет текст в .field-error. novalidate отключает стандартные подсказки браузера. Карточка успеха #armyResult скрыта атрибутом hidden, скрипт показывает её после успешной отправки. Поле name="name" — по этому имени скрипт берёт f.name.Әр өріс data-field="аты" бар орауышта жатыр — join.js-тегі holder(n) блокты соның арқылы тауып, .field-error-ға мәтін жазады. novalidate браузердің стандартты ескертулерін өшіреді. #armyResult сәттілік карточкасы hidden атрибутымен жасырылған, скрипт оны сәтті жібергеннен кейін көрсетеді. name="name" өрісі — скрипт f.name мәнін осы ат бойынша алады.Every field sits in a wrapper with data-field="name" — join.js’s holder(n) finds the block by it and writes into .field-error. novalidate turns off the browser’s own hints. The success card #armyResult is hidden with hidden; the script shows it after a successful submit. The field name="name" is how the script reads f.name.

Все цвета и шрифты заданы в :root как переменные --violet, --text и т.д. и используются через var(--violet). Это даёт единый стиль на всех страницах (критерий 5: «те же цвета, шрифты, отступы») — меняем в одном месте. Шрифты Syne и DM Sans лежат в fonts/ и подключены через @font-face.Барлық түс пен қаріп :root-та --violet, --text т.б. айнымалылар ретінде берілген және var(--violet) арқылы қолданылады. Бұл барлық беттерде бірыңғай стиль береді (5-критерий: «бірдей түстер, қаріптер, шегіністер») — бір жерде өзгертеміз. Syne және DM Sans қаріптері fonts/ ішінде жатыр және @font-face арқылы қосылған.All colours and fonts are defined in :root as variables --violet, --text etc. and used via var(--violet). This gives one style across pages (criterion 5: “same colours, fonts, spacing”) — change in one place. Fonts Syne and DM Sans live in fonts/ and are loaded with @font-face.

:focus-visible рисует розовую рамку вокруг кнопки или ссылки, когда на неё перешли клавишей Tab. Это требование критерия 1: «у каждой ссылки, кнопки и поля видимый фокус».:focus-visible батырмаға немесе сілтемеге Tab пернесімен өткенде қызғылт жиек салады. Бұл 1-критерийдің талабы: «әр сілтеме, батырма және өрістің көрінетін фокусы бар».:focus-visible draws a pink outline around a button or link when reached with Tab. This is criterion 1: “every link, button and field has a visible focus”.

CSS: светлая тема и адаптивностьCSS: жарық тақырып және бейімделгіштікCSS: light theme and responsiveness

css/style.css

1934[data-theme="light"]{color-scheme:light;--text:#1d1237;--muted:#5d4f7a;--glass:rgba(255,255,255,.72);--line:rgba(90,50,160,.2)}

Светлая тема — это блок правил с селектором [data-theme="light"]: он срабатывает, когда main.js ставит этот атрибут на <html>. Адаптивность: медиа-запросы @media (max-width: 900px) (строка 1619) и (max-width: 640px) (строка 1728) перестраивают раскладку для планшета (768 px) и телефона (375 px). Блок @media (prefers-reduced-motion: reduce) (строка 1876) отключает анимации тем, кто попросил об этом в системе.Жарық тақырып — [data-theme="light"] селекторлы ережелер блогы: main.js бұл атрибутты <html>-ге қойғанда іске қосылады. Бейімделгіштік: @media (max-width: 900px) (1619-жол) және (max-width: 640px) (1728-жол) медиа-сұраныстары планшет (768 px) және телефон (375 px) үшін орналасуды өзгертеді. @media (prefers-reduced-motion: reduce) блогы (1876-жол) жүйеде сұраған адамдар үшін анимацияны өшіреді.The light theme is a block of rules with selector [data-theme="light"]: it applies when main.js sets that attribute on <html>. Responsiveness: media queries @media (max-width: 900px) (line 1619) and (max-width: 640px) (line 1728) rearrange the layout for tablet (768 px) and phone (375 px). The @media (prefers-reduced-motion: reduce) block (line 1876) disables animations for people who asked for that in their system.
