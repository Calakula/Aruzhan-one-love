Для каждой кнопки: если она уже активна — return (защита от повторных кликов, лишний рендер не нужен). Әйтпесе оның data-filter мәнін filter-ге есте сақтап, active класын ауыстырамыз (x === b батырмада қосу, қалғанында өшіру) және render() шақырамыз.For each button: if it is already active — return (repeat-click guard, no extra render). В чём разница между map и filter?map мен filter айырмасы неде?What is the difference between map and filter?
map преобразует каждый элемент и возвращает массив той же длины (у нас — из массивов в объекты). filter возвращает только элементы, для которых функция вернула true — массив может быть короче.
map әр элементті түрлендіріп, сондай ұзындықтағы массив қайтарады (бізде — массивтерден нысандарға). filter функция true қайтарған элементтерді ғана қайтарады — массив қысқа болуы мүмкін.
map transforms each element and returns an array of the same length (here: arrays → objects). filter returns only elements for which the function returned true — the array can be shorter.
Почему render() каждый раз перестраивает всю таблицу?render() неге кестені әр рет толық қайта құрады?Why does render() rebuild the whole table every time?
Для 18 строк это мгновенно и проще: одно место, где собирается вид из состояния (filter + текст поиска). Для тысяч строк лучше обновлять только изменившиеся.
18 жол үшін бұл лезде әрі қарапайым: күйден (filter + іздеу мәтіні) көрініс жиналатын бір ғана орын. Мыңдаған жол үшін тек өзгергенін жаңартқан дұрыс.
For 18 rows it is instant and simpler: one place that builds the view from the state (filter + search text). For thousands of rows update only what changed.
Зачем String(a.year)?String(a.year) неге керек?Why String(a.year)?
year — число, а у чисел нет метода indexOf. Превращаем в строку, чтобы искать по году («2020» найдёт Dynamite, BE, Map of the Soul: 7).
year — сан, ал сандарда indexOf әдісі жоқ. Жыл бойынша іздеу үшін жолға айналдырамыз («2020» Dynamite, BE, Map of the Soul: 7 табады).
year is a number and numbers have no indexOf. Convert to a string to search by year (“2020” finds Dynamite, BE, Map of the Soul: 7).
Что вернёт list.length, если ничего не найдено, и что произойдёт?Ештеңе табылмаса list.length не қайтарады және не болады?What is list.length when nothing matches, and what happens?
0. Тогда empty.hidden = false (сообщение видно), а таблица скрыта через display: none.
0. Сонда empty.hidden = false (хабар көрінеді), ал кесте display: none арқылы жасырылады.
0. Then empty.hidden = false (message visible) and the table is hidden with display: none.
Как добавить сортировку или счётчик «Показано N из 18»?Сұрыптауды немесе «18-ден N көрсетілді» санағышын қалай қосуға болады?How would you add sorting or a “Showing N of 18” counter?
Счётчик: после filter записать list.length и albums.length в новый элемент (это и есть вычисляемое значение). Сортировка: list.sort(function (a, b) { return a.year - b.year; }) перед циклом.
Санағыш: filter-ден кейін list.length және albums.length мәндерін жаңа элементке жазу (бұл есептелетін мән). Сұрыптау: циклден бұрын list.sort(function (a, b) { return a.year - b.year; }).
Counter: after filter write list.length and albums.length into a new element (that is your calculated value). Sorting: list.sort(function (a, b) { return a.year - b.year; }) before the loop.
