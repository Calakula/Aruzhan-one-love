# Borahae — Endterm defense prep

Static site (HTML + CSS + vanilla JS), no build step, works on GitHub Pages.
Languages: RU / ҚАЗ / EN (switcher in the header, choice is remembered).

## Deploy on GitHub Pages
1. Create a new repository (e.g. `borahae-defense-prep`) and upload the contents of this folder
   so that `index.html` is in the repository root (keep `css/`, `js/`, `.nojekyll`).
2. Repository → Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save.
3. After a minute the site is at `https://<your-login>.github.io/<repo>/`.

Open locally: just double-click `index.html` (no server needed).
Direct language link: `index.html?lang=kk`.
