Форма сделана без alert(): каждая ошибка пишется под своим полем и исчезает, когда поле исправлено. Все правила собраны в один объект rules: ключ — имя поля, значение — функция, которая возвращает текст ошибки или ничего (если всё верно). Одна функция check умеет проверить любое поле, поэтому код короткий.Форма alert() жоқ жасалған: әр қате өз өрісінің астына жазылады және өріс түзетілгенде жоғалады. Барлық ережелер бір rules нысанына жиналған: кілт — өріс аты, мән — қате мәтінін немесе ештеңе қайтаратын функция (бәрі дұрыс болса). Бір check функциясы кез келген өрісті тексереді, сондықтан код қысқа.The form uses no alert(): each error is written under its own field and disappears when the field is fixed. All rules live in one rules object: key = field name, value = a function returning the error text or nothing (if valid). One check function can validate any field, so the code stays short.

Почему у формы novalidate и почему нет alert()?Форманың novalidate атрибуты неге бар және alert() неге жоқ?Why novalidate on the form and why no alert()?
novalidate отключает встроенные всплывашки браузера — мы показываем свои сообщения под полем. alert() блокирует страницу и запрещён брифом (ошибки должны быть под полем и исчезать при исправлении).
novalidate браузердің кірістірілген қалқымалы хабарларын өшіреді — біз өз хабарларымызды өрістің астында көрсетеміз. alert() бетті бұғаттайды және брифпен тыйым салынған (қателер өріс астында болып, түзетілгенде жоғалуы керек).
novalidate turns off the browser’s built-in bubbles — we show our own under the field. alert() blocks the page and is banned by the brief (errors must be under the field and vanish when fixed).
Что делает /^\d{4}$/?/^\d{4}$/ не істейді?What does /^\d{4}$/ do?
^ — начало строки, \d — цифра, {4} — ровно 4 раза, $ — конец строки. Значит, строка состоит ровно из четырёх цифр.
^ — жол басы, \d — сан, {4} — дәл 4 рет, $ — жол соңы. Демек, жол дәл төрт саннан тұрады.
^ is the start of the string, \d a digit, {4} exactly four times, $ the end. So the string is exactly four digits.
Зачем собирать правила в объект, а не писать if для каждого поля?Неге әр өріске if жазбай, ережелерді нысанға жинаймыз?Why gather rules in an object instead of an if per field?
Одна функция check и один цикл обслуживают все поля. Чтобы добавить поле, достаточно новой записи в rules и разметки с data-field — остальной код не меняется.
Бір check функциясы мен бір цикл барлық өрісті қызмет етеді. Өріс қосу үшін rules-қа жаңа жазба және data-field белгілемесі жеткілікті — қалған код өзгермейді.
One check function and one loop serve every field. To add a field you only add an entry to rules and markup with data-field — nothing else changes.
Почему при отправке вызывается map(check), а не останавливаемся на первой ошибке?Жібергенде неге бірінші қатеде тоқтамай, map(check) шақырылады?Why does submit use map(check) instead of stopping at the first error?
Чтобы показать пользователю сразу все ошибки, а не по одной. map проходит по всем полям и возвращает массив результатов.
Пайдаланушыға барлық қатені бірден көрсету үшін, бір-бірлеп емес. map барлық өрісті аралап, нәтижелер массивін қайтарады.
To show all errors at once, not one by one. map visits every field and returns an array of results.
Что будет, если вызвать form.reset() до чтения значений?form.reset()-ті мәндерді оқымай тұрып шақырса не болады?What happens if form.reset() is called before reading the values?
Поля станут пустыми, и на карточке окажутся пустые имя и bias. Поэтому объект d создаётся раньше (строка 38).
Өрістер бос болады да, карточкада есім мен bias бос шығады. Сондықтан d нысаны ертерек жасалады (38-жол).
Fields become empty and the card would show an empty name and bias. That is why d is created earlier (line 38).
