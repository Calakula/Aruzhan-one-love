Что делает IntersectionObserver и чем он лучше события scroll?IntersectionObserver не істейді және scroll оқиғасынан несімен жақсы?What does IntersectionObserver do and why is it better than the scroll event?
Сообщает, когда элемент входит в область видимости. Браузер сам оптимизирует проверку, не нужно вручную считать позиции на каждом scroll — меньше нагрузки на страницу.
Элемент көру аймағына кірген кезде хабарлайды. Браузер тексеруді өзі оңтайландырады, әр scroll сайын орындарды қолмен есептеудің қажеті жоқ — беттің жүктемесі аз.
It reports when an element enters the viewport. The browser optimises the check itself, so you do not compute positions on every scroll — less load on the page.
Зачем класс tl-js?tl-js класы неге керек?Why the tl-js class?
Чтобы CSS скрывал карточки только если JS работает. Если JS не загрузился, карточки видны сразу, а не остаются невидимыми навсегда.
CSS карточкаларды тек JS жұмыс істесе ғана жасыруы үшін. JS жүктелмесе, карточкалар бірден көрінеді, мәңгі көрінбей қалмайды.
So CSS hides cards only when JS works. If JS fails to load, the cards are visible at once instead of staying invisible forever.
Зачем unobserve?unobserve неге керек?Why unobserve?
Анимация нужна один раз. После появления перестаём следить — меньше работы, и карточка не «мигает» при повторной прокрутке.
Анимация бір рет қана қажет. Пайда болғаннан кейін бақылауды тоқтатамыз — жұмыс аз, ал қайта айналдырғанда карточка «жыпылықтамайды».
The animation is needed once. After it appears we stop watching — less work and the card does not “blink” on re-scroll.
Почему у карточки role="button" и tabIndex = 0?Карточкада role="button" және tabIndex = 0 неге бар?Why role="button" and tabIndex = 0 on the card?
div по умолчанию не получает фокус и не воспринимается как кнопка. Эти два атрибута дают клавиатурный доступ (Tab + Enter) — требование критерия 1.
div әдепкіде фокус алмайды және батырма ретінде қабылданбайды. Бұл екі атрибут пернетақта қолжетімділігін (Tab + Enter) береді — 1-критерийдің талабы.
A div is not focusable and not seen as a button by default. These two attributes give keyboard access (Tab + Enter) — a criterion 1 requirement.
