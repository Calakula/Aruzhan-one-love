Зачем void fig.offsetWidth?void fig.offsetWidth неге керек?Why void fig.offsetWidth?
Чтобы перезапустить CSS-анимацию: сначала убираем класс, потом читаем offsetWidth (браузер вынужден применить изменения — reflow), потом снова добавляем класс. Без этого браузер «склеит» два изменения и анимация не повторится.
CSS-анимацияны қайта іске қосу үшін: алдымен класты алып тастаймыз, сосын offsetWidth оқимыз (браузер өзгерістерді қолдануға мәжбүр — reflow), сосын класты қайта қосамыз. Онсыз браузер екі өзгерісті «біріктіріп» жібереді де, анимация қайталанбайды.
To restart a CSS animation: remove the class, read offsetWidth (forces the browser to apply changes — reflow), then add the class again. Without it the browser merges both changes and the animation does not replay.
Чем requestAnimationFrame лучше setInterval для анимации?Анимация үшін requestAnimationFrame неге setInterval-дан жақсы?Why is requestAnimationFrame better than setInterval for animation?
Он синхронизирован с частотой обновления экрана, ставится на паузу в неактивной вкладке и не рисует лишних кадров — плавнее и экономит батарею.
Ол экранның жаңарту жиілігімен синхрондалған, белсенді емес қойындыда тоқтап тұрады және артық кадр салмайды — тегіс әрі батареяны үнемдейді.
It is synced with the screen refresh rate, pauses in a hidden tab and draws no extra frames — smoother and saves battery.
Почему музыка сама не стартует?Музыка неге өзі басталмайды?Why does the music not start by itself?
Браузеры блокируют автовоспроизведение со звуком без действия пользователя. play() отклоняет Promise с NotAllowedError; мы его ловим и ждём клика на кнопку.
Браузерлер пайдаланушы әрекетінсіз дыбысты автоойнатуды бұғаттайды. play() Promise-ты NotAllowedError қатесімен қабылдамайды; біз оны ұстап, батырманы басуды күтеміз.
Browsers block autoplay with sound without a user gesture. play() rejects its Promise with NotAllowedError; we catch it and wait for a button click.
Как считаются дни/часы/минуты/секунды?Күн/сағат/минут/секунд қалай есептеледі?How are days/hours/minutes/seconds calculated?
Разница дат в миллисекундах делится на размер единицы; для меньших единиц сначала берём остаток (%) от большей. Пример: часы = (diff % 86400000) / 3600000.
Күндер айырмасы миллисекундпен бірлік өлшеміне бөлінеді; кіші бірліктер үшін алдымен үлкенінен қалдық (%) аламыз. Мысалы: сағат = (diff % 86400000) / 3600000.
The date difference in milliseconds is divided by the unit size; for smaller units take the remainder (%) of the larger first. Example: hours = (diff % 86400000) / 3600000.
